# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of `@francofantomius/docs-gen` seriously. If you discover a security vulnerability, please do NOT create a public GitHub issue.

Instead, please report it via one of the following methods:

1. **GitHub Security Advisory**: Open a private draft security advisory at [https://github.com/FrancoFantomius/docs-gen/security/advisories/new](https://github.com/FrancoFantomius/docs-gen/security/advisories/new).
2. **Direct Contact**: Reach out privately through GitHub at [https://github.com/FrancoFantomius](https://github.com/FrancoFantomius).

### What to Include

Please provide:
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue (including any minimal reproduction code or configuration).
- Any proposed remediation or mitigation steps if known.

We will acknowledge receipt within 48 hours and work on a fix as quickly as possible.
