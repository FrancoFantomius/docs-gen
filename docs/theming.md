# Theming & Color Palettes

`@francofantomius/docs-gen` is built from the ground up on Google's **Material Design 3 (M3)** design system.

---

## Built-In Light, Dark, and System Modes

The top application bar includes a theme toggle button:
- **Light Mode**: High-contrast, clean light surfaces with M3 tonal containers.
- **Dark Mode**: Low-glare dark surfaces adhering to M3 dark elevation and container tokens.
- **System Mode**: Follows the user's operating system preferences (`prefers-color-scheme`).

The user's theme selection is automatically saved in browser `localStorage` and persists across visits.

---

A palette picker dialog in the top app bar allows visitors to change the primary accent color on the fly. Available palettes:

## Client-Side Search

Every documentation site generated by `docs-gen` includes an instant client-side search bar:

- **Keyboard Shortcut**: Press `/` or `Ctrl + K` (`Cmd + K` on macOS) to focus the search bar from anywhere on the page.
- **Fuzzy Search**: Automatically indexes page titles, descriptions, categories, and badges.
- **Keyboard Navigation**: Use arrow keys and `Enter` to jump straight to any documentation topic.
